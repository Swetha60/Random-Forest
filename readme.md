# Task 8: Random Forest

##  Project Overview

In this task, I implemented Random Forest and compared its performance with a Decision Tree model using the Breast Cancer dataset. The objective was to understand ensemble learning and how combining multiple models improves accuracy.

---

##  Tools Used

* Python
* NumPy
* Pandas
* Scikit-learn

---

##  Dataset

I used the Breast Cancer dataset available in sklearn.

* Target values:

  * 0 → Malignant (Cancerous)
  * 1 → Benign (Non-cancerous)


##  Steps Performed

1. Loaded the dataset using sklearn
2. Converted the dataset into a Pandas DataFrame
3. Separated features (X) and target (y)
4. Split the data into training and testing sets
5. Implemented Decision Tree model
6. Implemented Random Forest model
7. Compared accuracy of both models
8. Analyzed feature importance


##  Results

* Random Forest achieved better accuracy compared to Decision Tree
* Feature importance helped identify the most important features
* Ensemble learning improved model performance


## Concepts Learned

* Decision Tree vs Random Forest
* Ensemble learning
* Bagging technique
* Feature importance
* Overfitting reduction
##  Conclusion

This task helped me understand how Random Forest combines multiple decision trees to improve accuracy and reduce overfitting compared to a single Decision Tree model.
